Your four discount scenarios
1
"First X months free"
Ready to set up
Use the real subscription product (e.g., Endor Package Firewall) with a scheduled 100% discount for the promo months. After the free period, it flips to full price automatically. Renewal generates clean — no manual work.
What reps do daily (after setup)
Pick "Promo" blueprint → Choose product + free months → Done — pricing auto-calculates
Setup steps (our working session)
  1. Add the subscription SKU (e.g., Endor Package Firewall) at full list price for the full contract term
  2. Apply 100% percentage discount + flag as "removed at renewal"
  3. Add a schedule change at month 4 (or whenever promo ends) setting discount to 0%
  4. Save as blueprint — reps select this template for every promo deal going forward

Why this is better
Same result for the customer, but renewal auto-generates correctly — no manual swap. Reporting stays clean too, since you can track which accounts got promos without creating separate products. We can phase out the promo products once you're comfortable with the new setup.
Distinction to keep in mind
One-Time = a product type that charges once and isn't recurring (like the promo products you created).
One-Time Discount = a quote-level discount product where you set the discount amount during quote creation (Scenario 4 above). Different things — easy to mix up.
